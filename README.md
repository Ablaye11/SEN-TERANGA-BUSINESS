# SEN TERANGA BUSINESS 🇸🇳

Une plateforme complète de gestion de vente et de stock pour boutique de smartphones et d'ordinateurs.

## 🚀 Fonctionnalités
- **Point de Vente (POS)** : Interface rapide avec support scanner de code-barres/IMEI.
- **Gestion de Stock** : Suivi précis par IMEI/Série avec cycle de vie (Entrée > Vente > SAV).
- **CRM & Fidélité** : Gestion des clients avec badges VIP et intégration WhatsApp.
- **Service Après-Vente (SAV)** : Suivi complet des réparations et impression de tickets.
- **Intelligence Business** : Graphiques d'évolution des ventes et calcul des profits.
- **Sécurité** : Journal d'audit complet des modifications système.

## 📱 Mobile-First
L'application est entièrement optimisée pour une utilisation sur smartphone et tablette.

## 🛠️ Installation
1. Installez les dépendances : `pip install -r requirements.txt`
2. Migrez la base de données : `python manage.py migrate`
3. Lancez le serveur : `python manage.py runserver`
